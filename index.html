Services réseau sous Ubuntu Server 2026 SSH, FTP et HTTP configurés sur un serveur Ubuntu, protégés par le pare-feu UFW, et testés depuis un client Windows 11.

Ce que j'ai fait

  1. Mise à jour du serveur puis vérification de son adresse IP avec ip a.
  2. SSH : installation d'OpenSSH, démarrage automatique au boot, puis connexion à distance depuis le client Windows 11.
  3. FTP : installation de vsftpd et configuration sécurisée : pas de connexion anonyme, chaque utilisateur enfermé dans son dossier (chroot_local_user=YES).
  4. HTTP : installation d'Apache2 et publication d'une page web dans /var/www/html/.
  5. Contrôle : vérification des ports ouverts avec ss -tulpn.
  6. Pare-feu : activation d'UFW et ouverture des seuls ports nécessaires (22, 21 et 80).
lamine@ubuntuserver:~$ sudo apt install openssh-server vsftpd apache2
lamine@ubuntuserver:~$ sudo systemctl enable ssh
lamine@ubuntuserver:~$ sudo nano /etc/vsftpd.conf
lamine@ubuntuserver:~$ sudo ufw allow ssh && sudo ufw allow ftp && sudo ufw allow http
lamine@ubuntuserver:~$ sudo ufw enable
